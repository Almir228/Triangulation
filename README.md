# Triangulation: учебный прототип геометрии треугольника

Небольшой проект на C++17 для изучения трёхмерных векторов и геометрии треугольника. **Программа выравнивает длины сторон одного заданного в коде треугольника; триангуляция облака точек или построение сетки пока не реализованы.**

## Задача и математическая идея

Для длин сторон `a`, `b`, `c` отклонение от равносторонней формы вычисляется как

```text
(max(a, b, c) - min(a, b, c)) / max(a, b, c)
```

`improveEquilateral` последовательно сдвигает одну вершину самой длинной стороны на долю `delta` в сторону другой вершины. Остановка происходит, когда отклонение становится меньше `tolerance`. По умолчанию `delta = 1e-4`, `tolerance = 1e-3`. Это эвристика, меняющая координаты вершин и способная уменьшить треугольник; доказательства оптимальности или гарантии качества сетки нет.

## Структура и алгоритм

- `Point3D`: векторная арифметика, расстояние и вывод координат.
- `Triangle`: площадь через векторное произведение, длины сторон, оценка формы и итерационная корректировка.
- `contains`: вычисления в барицентрических координатах; компланарность и вырожденные входные данные не проверяются.
- `isDelaunaySatisfied`: экспериментальная вспомогательная функция с определителем, не используемая в демонстрации. Ориентация и поведение в 3D не проверены; считать её корректным общим предикатом Делоне нельзя.
- `main.cpp`: перечисленные реализации и фиксированный пример.
- `CMakeLists.txt`: сборка одной программы только со стандартной библиотекой. Неиспользуемая зависимость SFML удалена.

## Сборка и запуск

Нужны компилятор C++17 и CMake 3.10+:

```bash
cmake -S . -B build
cmake --build build
./build/triangulation
```

Другой способ: `c++ -std=c++17 main.cpp -o triangulation`, затем `./triangulation`.

## Пример входных данных и результата

Координаты заданы в `main()`, чтения из stdin нет: `(0,0,6)`, `(1,0,0)`, `(0,3,0)`.

Полученный вывод с параметрами по умолчанию (последние цифры могут отличаться):

```text
Before deviation from equilateral: 0.528595
Triangle points:
Point(0.56623, 0, 2.60262)
Point(1, 0, 0)
Point(0.0799803, 2.16928, 1.18155)
After deviation from equilateral: 0.000968854
```

## Связь с Triangulation_1

[Triangulation_1](https://github.com/Almir228/Triangulation_1) — более поздний экспериментальный вариант: добавлены векторные функции и контейнер `Triangles`, заменён `contains`, а из `improveEquilateral` убран шаг обновления вершин. В его демонстрации форма не меняется. Этот репозиторий рекомендуется как исходная рабочая версия: показанная корректировка здесь работает. Сообщения коммитов не объясняют причину создания двух репозиториев.

## Ограничения и дальнейшая работа

Нет ввода множества точек, экспорта сетки, визуализации, ограничения числа итераций и устойчивой обработки нулевых сторон или коллинеарных точек. Некорректные параметры могут помешать сходимости. Следующие шаги — проверка граничных случаев и устойчивые геометрические предикаты, затем реализация настоящего алгоритма триангуляции. Ни одна версия не является законченной численной библиотекой.
