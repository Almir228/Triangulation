# Повороты коэффициентов Чебышёва вокруг оси Z

После канонизации векторная площадь контура направлена вдоль `+Z`. Остаточное
действие вращений — группа `SO(2)` в плоскости XY. Модуль
`python/minsurf_nn/rotations.py` реализует это действие на коэффициентах
total-degree разложения без повторного fitting поверхности.

Для фиксированной степени по Z, `k`, используется пространство

\[
\{T_i(x)T_j(y):i+j\leq p-k\}.
\]

Вводятся `w=x+iy` и `wbar=x-iy`. Матрица `S` переводит коэффициенты из
Chebyshev-базиса в комплексные мономы:

\[
d=Sc,
\qquad
\{w^m\bar w^n:m+n\leq p-k\}.
\]

Обе матрицы строятся независимо в SymPy над точным полем `Q(i)`:

* столбцы `S` получаются разложением `T_i(x)T_j(y)` после подстановки
  `x=(w+wbar)/2`, `y=(w-wbar)/(2i)`;
* `S^{-1}` получается обратным разложением каждого `w^m wbar^n` через степени
  `x,y`, а затем через Chebyshev-полиномы;
* до перехода к числам проверяются точные равенства
  `S*S_inverse == I` и `S_inverse*S == I`.

После этого матрицы единожды преобразуются в `complex128`. Благодаря вложенности
пространств меньшие блоки извлекаются из максимального блока. Для полного
пространства степени `p` блоки раскладываются по фиксированному `k` в порядке,
совместимом с `total_degree_indices(p)`.

## Соглашение о знаке

Реализованная буквально формула из исходного промпта

\[
c'=S_p^{-1}D_p(\varphi)S_pc,
\qquad
D_{mn}(\varphi)=e^{i(m-n)\varphi},
\]

означает поворот системы координат:

\[
F_{c'}(x,y,z)=F_c(R_\varphi(x,y),z).
\]

Ей соответствует функция `rotate_coordinate_coefficients`. Для augmentation
обычно требуется активный поворот контура и самой поверхности на `+phi`.
Тогда используется противоположный угол внутри формулы, что уже учтено в
`rotate_surface_coefficients`:

```python
import numpy as np

from minsurf_nn.rotations import rotate_surface_coefficients, rotate_xy_points

phi = np.pi / 5
rotated_contour = rotate_xy_points(contour, phi)
rotated_coefficients = rotate_surface_coefficients(coefficients, degree=10, angle=phi)
```

Для любой точки исходной поверхности выполняется

\[
F_{c_{\rm rotated}}(R_\varphi x)=F_c(x).
\]

Функции работают и с массивом коэффициентов формы `[batch,K]`. Если входные
коэффициенты действительные, малый numerical imaginary residual проверяется и
удаляется; результат также имеет действительный dtype.

## Сохранённые матрицы степени 10

Готовые `S^(10)` и `S^(10)^-1` уже хранятся в репозитории:

```text
python/minsurf_nn/assets/chebyshev_so2_degree10.npz
```

Размер файла — около 28 КБ. При `degree=10` runtime автоматически загружает
его, проверяет metadata, индексацию и произведение матриц, после чего кэширует
массивы в памяти процесса. SymPy при обычном повороте степени 10 не импортируется.
Локальный холодный запуск с загрузкой и одним поворотом занимает около 0.1
секунды.

Для воспроизводимой регенерации файла из точной арифметики используется:

```bash
python3 scripts/build_rotation_matrices.py \
  --degree 10 \
  --output python/minsurf_nn/assets/chebyshev_so2_degree10.npz \
  --force
```

NPZ содержит:

* `chebyshev_to_complex [286,286]` — `S_p`;
* `complex_to_chebyshev [286,286]` — `S_p^{-1}`;
* `indices [286,3]` — общую индексацию `(i,j,k)` или `(m,n,k)`;
* metadata с соглашением и ошибкой численной проверки identity.

SHA-256 текущего ресурса:
`e42153ceb7d649c8031fc4f347cb08b91c9ebffee2477d9449ea822a8cc6226e`.
Точная регенерация степени 10 на текущей машине занимает около пяти секунд.
Для других степеней матрицы пока строятся точно при первом обращении и затем
кэшируются в памяти; их также можно заранее экспортировать тем же скриптом.

## Проверяемые свойства

Unit tests проверяют:

1. точное двустороннее обращение матриц в SymPy;
2. совпадение преобразования коэффициентов с непосредственным поворотом точек;
3. `M(phi1)M(phi2)=M(phi1+phi2)` и identity при `2*pi`;
4. действительность результата для действительной функции;
5. сохранение нормы коэффициентов в диагональном complex representation;
6. правильный знак активного поворота поверхности;
7. batch-преобразование и повторное использование экспортированного NPZ.

## Размножение готового датасета

`scripts/augment_chebyshev_dataset_parallel.py` создаёт компактные пакеты
rotation augmentation, не запуская Plateau solver и не повторяя fitting:

```bash
mkdir -p runs
caffeinate -i python3 -u scripts/augment_chebyshev_dataset_parallel.py \
  dataset/plateau-100k-chebyshev-p10/manifest.jsonl \
  --copies 8 --workers 6 \
  --output-dir dataset/plateau-100k-chebyshev-p10-rot8 \
  2>&1 | tee runs/plateau-100k-chebyshev-p10-rot8.log
```

`--copies 8` означает восемь пар на каждый исходный контур: первая имеет угол
ноль, остальные семь получают воспроизводимые независимые углы из
`U[0,2*pi)`. Итого из 100 000 независимо сгенерированных поверхностей получается
800 000 обучающих пар. `--exclude-original` делает случайными все восемь углов.
Seed и число копий входят в fingerprint конфигурации.

В режиме `auto` скрипт находит исходный `generation_config.json` и детерминированно
воспроизводит только контур по его seed. Это даёт в точности те же массивы
`boundary_points`, но не обращается к mesh-NPZ и не запускает Plateau solver.
Локальная проверка дала нулевое побитовое различие для 64- и 128-точечного
контуров. Если входной набор получен не штатным генератором, используется чтение
NPZ; его можно запросить явно как `--contour-source npz`. На macOS опция
`--hydrate-icloud` дополнительно загружает встреченные `dataless`-файлы.

Каждый выходной NPZ соответствует одной исходной поверхности и содержит:

* `boundary_points [copies,64,3]`;
* `coefficients [copies,286]`;
* `coefficient_energy [copies,11]`;
* `angles [copies]`;
* общие `indices [286,3]`, `degree` и `source_index`;
* metadata с convention, fingerprint и результатом численной проверки.

Ground-truth mesh намеренно не копируется восемь раз. Его путь остаётся в
manifest, а требуемая поверхность получается как `R_z(phi) @ vertices`. Поэтому
число физических файлов остаётся равным 100 000, а ожидаемый размер при восьми
копиях — около 3 ГиБ, а не восьмикратная копия всего mesh-датасета.

Benchmark на 1000 настоящих `p=10` samples с шестью worker-процессами занял
1.46 секунды (около 685 исходных поверхностей или 5480 виртуальных примеров в
секунду). Для полного набора с учётом большого числа файлов разумно ожидать
несколько минут; фактический темп и ETA печатаются во время работы.

Для каждого пакета скрипт проверяет на независимых точках тождество функций

\[
F_{c_\varphi}(R_\varphi x)=F_c(x).
\]

Допуск задаётся `--verification-tolerance`; максимум по всему набору попадает в
`augmentation_summary.json`. Запись атомарная, manifest пополняется по мере
работы, неудачи записываются в `failures.jsonl`, повтор той же команды продолжает
незавершённый проход. Это тождество на всём пространстве сохраняет как нулевой
уровень, так и исходную fitting-ошибку на повернутом ground-truth mesh.

Пакеты можно раскрывать в отдельные примеры без загрузки всего набора в память:

```python
from minsurf_nn.data import (
    AugmentedChebyshevDataset,
    read_manifest,
    split_records,
)

records = read_manifest(
    "dataset/plateau-100k-chebyshev-p10-rot8/manifest.jsonl"
)
train_records, validation_records = split_records(records)
train = AugmentedChebyshevDataset(train_records, boundary_count=64)

sample = train[0]
# sample["boundary"]: [64,3]
# sample["coefficients"]: [286]
```

Split и `group_id` сохраняются на уровне исходной поверхности: разные повороты
одного контура не могут попасть одновременно в train и validation.
