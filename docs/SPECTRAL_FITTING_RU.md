# Аппроксимация триангуляции полиномом Чебышёва

Модуль `python/minsurf_nn/spectral.py` строит конечный полином

\[
F_p(x,y,z)=\sum_{i+j+k\le p}c_{ijk}T_i(x)T_j(y)T_k(z)
\]

по заданной ориентированной триангуляции. Используется именно базис полной
степени, поэтому число коэффициентов равно

\[
K(p)=\binom{p+3}{3}.
\]

Это независимый численный fitting, не обучение нейросети.

## Предположения

Перед fitting автоматически проверяется, что:

- все вершины лежат в кубе `[-1, 1]^3`;
- сетка имеет границу и не содержит неманифолдных рёбер;
- соседние треугольники ориентированы согласованно;
- треугольники невырождены;
- суммарный вектор ориентированных площадей параллелен `+z`.

Последняя величина для сетки вычисляется как

\[
A=\frac12\sum_f
(v_{f,1}-v_{f,0})\times(v_{f,2}-v_{f,0}).
\]

Она совпадает с векторной площадью ориентированной границы, поскольку вклады
внутренних рёбер сокращаются.

## Задача fitting

Точки равномерно по площади семплируются на треугольниках. Для точки `x` и
ориентированной единичной нормали `n` в систему least squares добавляются

\[
F_p(x)=0,\qquad F_p(x+d n)=d,\qquad F_p(x-d n)=-d.
\]

Расстояния `d` немного рандомизируются и автоматически уменьшаются рядом с
границей куба, чтобы обе смещённые точки оставались внутри `[-1,1]^3`.
Дополнительные точки на граничных рёбрах получают повышенный вес. Небольшая
регуляризация сильнее штрафует старшие полные степени.

Поскольку targets имеют размерность расстояния, после решения коэффициенты
не перенормируются: их масштаб и знак уже заданы локальным signed distance.

## Запуск

На нормированном NPZ с канонически ориентированной поверхностью:

```bash
python scripts/fit_chebyshev_surface.py path/to/canonical-surface.npz \
  --degree 10 --output runs/spectral/sample_000000_p10.npz
```

Старые samples из `dataset/v1` были созданы до реализации канонического
поворота: перед fitting их нужно повернуть либо сгенерировать заново.

Можно передать OBJ, если его координаты уже лежат в `[-1,1]^3`:

```bash
python scripts/fit_chebyshev_surface.py normalized-surface.obj --degree 10
```

Результат содержит `coefficients [K]`, `indices [K,3]`, степень и JSON metadata
с рангом системы, condition number и RMSE на поверхности, смещённых точках и
границе. Порядок коэффициентов фиксирован: сначала полная степень, затем
лексикографический обход `i`, `j`; координата `k` определяется из полной степени.
Регуляризация по умолчанию равна `1e-6` и меняется параметром `--ridge`.

Для fitting всего готового mesh-датасета используется параллельный,
возобновляемый скрипт `scripts/fit_chebyshev_dataset_parallel.py`. Он не меняет
исходные NPZ и создаёт отдельный manifest «контур/mesh → коэффициенты».
Инструкция и измеренная стоимость запуска на 100 000 samples приведены в
[`CHEBYSHEV_DATASET_RU.md`](CHEBYSHEV_DATASET_RU.md).

Нулевой уровень глобального полинома может продолжаться за край открытой плёнки
или содержать дополнительные компоненты. Поэтому геометрический участок всегда
нужно извлекать вместе с допустимой областью проекции контура.

## Convergence experiment

Полный прогон степеней выполняется командой:

```bash
python scripts/run_spectral_convergence.py dataset/spectral-pilot-r2/manifest.jsonl \
  --output runs/spectral-convergence-pilot --degrees 4,6,8,10,12,15
```

Для graph-поверхностей ближайшая ветвь нулевого уровня извлекается вертикальным
Newton solve на XY-топологии target mesh. Значения target Z используются только
как начальное приближение для выбора локальной ветви, но не копируются в
результат. Скрипт считает field residual, boundary residual, near-band error,
symmetric Chamfer RMSE, приближённый Hausdorff distance и relative area error.

Чувствительность к расстоянию смещения и весу границы исследуется отдельно:

```bash
python scripts/run_fitting_ablation.py dataset/spectral-pilot-r2/manifest.jsonl \
  --output runs/spectral-fitting-ablation-pilot
```

Результаты первого pilot зафиксированы в
[`SPECTRAL_PILOT_RU.md`](SPECTRAL_PILOT_RU.md).
