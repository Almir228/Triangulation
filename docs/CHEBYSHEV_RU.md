# Прямая аналитическая формула

Модель `ConditionalChebyshev` получает нормированный пространственный контур и
за один проход предсказывает коэффициенты конечного трёхмерного ряда Чебышёва:

\[
F_C(x,y,z)=\sum_{i,j,k=0}^{K}a_{ijk}(C)
T_i(x/E)T_j(y/E)T_k(z/E).
\]

Здесь `C` — входной контур, `K` задаётся через `--degree`, а `E` через
`--extent`. Нейросеть не подбирает коэффициенты отдельной оптимизацией при
инференсе: coefficient head выдаёт все `(K+1)^3` чисел одновременно. Второй
head непосредственно предсказывает нормированную минимальную площадь.

Для открытой плёнки одного глобального уравнения недостаточно: регулярный уровень
`F=0` обычно продолжается за закреплённый край. В текущем датасете проекция
контура на XY выпуклая, поэтому экспортируемый участок определяется парой условий

\[
F_C(x,y,z)=0, \qquad (x,y)\in\Omega_C,
\]

где `Ω_C` — внутренняя область проекции контура. Сгенерированный Python-файл
содержит функции `F`, `inside_domain` и `surface_contains`, коэффициенты,
нормализацию и оценку площади. Он работает без PyTorch и NumPy.

## Обучение

Пример небольшого запуска на локальном `dataset/v1`:

```bash
source .venv-ml/bin/activate
python scripts/train_chebyshev.py dataset/v1/manifest.jsonl \
  --output runs/chebyshev-v1 --epochs 100 --batch-size 4 \
  --query-count 512 --boundary-count 64 --degree 4 --device cpu
```

Помимо SDF, граничного, Eikonal и минимального штрафов используются:

- SmoothL1 по логарифму площади;
- спектральная регуляризация, сильнее штрафующая коэффициенты высоких порядков.

Параметр `--degree 3` даёт 64 коэффициента, `--degree 4` — 125, `--degree 6` —
343. Рост степени быстро увеличивает стоимость вычисления поля и риск лишних
компонент нулевого уровня.

## Экспорт

```bash
python scripts/export_chebyshev.py runs/chebyshev-v1/best.pt \
  dataset/v1/sample_000031.npz \
  --output runs/chebyshev-v1/surface_formula.py \
  --coefficients runs/chebyshev-v1/coefficients.npz \
  --obj runs/chebyshev-v1/surface.obj --resolution 64

python scripts/evaluate_prediction.py dataset/v1/sample_000031.npz \
  runs/chebyshev-v1/surface.obj
```

`--prune-relative` зануляет коэффициенты, меньшие заданной доли максимального,
и позволяет получить более короткую приближённую формулу. По умолчанию ничего
не отбрасывается.

На проверочном запуске степени 3 после 20 CPU-эпох модель выдала площадь `2.565`
при цели `2.685`. После отсечения по области проекции площадь сетки нулевого
уровня составила `3.277`. Это подтверждает работоспособность прямого экспорта,
но ещё не является хорошим решением: средняя ошибка поверхности равна примерно
`0.174` в мировых единицах. Для оценки обобщения нужны больший датасет и отдельные
семейства test-контуров.

Текущее отсечение по XY подходит для графиков и однозначных проекций. Для
нависающих поверхностей и сложной топологии понадобится второй аналитический
предиктор области `G_C(x,y,z)≤0` либо параметризация нескольких карт.
