# Прототип условной неявной поверхности

Сеть на Python/PyTorch получает точки одного замкнутого пространственного контура
и предсказывает скалярное поле в произвольных 3D-точках. Это исследовательский
baseline: наличие работающего обучения не доказывает преимущество над решателем.

## Установка и запуск

Из корня репозитория, предпочтительно в отдельном виртуальном окружении:

```bash
python3 -m venv .venv-ml
source .venv-ml/bin/activate
python -m pip install -r requirements-ml.txt
python scripts/train_implicit.py datasets/minsurf/manifest.jsonl --output runs/implicit --epochs 100
python scripts/predict_implicit.py runs/implicit/best.pt datasets/minsurf/sample_000000.npz --output runs/implicit/prediction.obj --field-output runs/implicit/field.npz
```

Имена каталога и NPZ замените на фактический вывод генератора. `--help` не требует
установленного PyTorch. Для короткой проверки используйте `--epochs 1 --max-batches 1
--batch-size 2 --query-count 64 --boundary-count 32 --hidden-dim 32 --latent-dim 16
--layers 2 --frequencies 2 --eikonal-samples 16 --device cpu`.

`auto` выбирает CUDA при наличии, иначе CPU. Apple MPS в этом прототипе не используется,
чтобы не зависеть от поддержки вторых производных конкретными операциями MPS.
По умолчанию используются четыре CPU-потока. Это не фоновый сервис: обучение
выполняется запущенным процессом до завершения указанного количества эпох.

## Контракт данных

`manifest.jsonl` содержит по одному JSON-объекту на строку:

```json
{"path": "samples/000001.npz", "split": "train", "group_id": "contour_000001"}
```

`path` считается относительно manifest. Допускаются aliases `file` и `npz`.
`split` может быть `train`, `val` (`validation`) или `test`. Если он указан хотя бы
для одного примера, он обязателен для всех. `test` не участвует ни в обучении,
ни в подборе checkpoint. Без явного split выполняется воспроизводимое разделение
по примерам/`group_id`, а не по query-точкам. Вариации одного исходного контура
следует объединять одинаковым `group_id`; необходимы минимум две независимые группы.

NPZ загружается с `allow_pickle=False`:

| Ключ | Размер | Смысл |
|---|---|---|
| `boundary_points` | `[B, 3]`, float32 | Упорядоченный замкнутый контур; повтор последней точки допустим |
| `query_points` | `[Q, 3]`, float32 | Точки запросов |
| `signed_distance` | `[Q]`, float32 | Локальное ориентированное расстояние |
| `surface_vertices` | `[V, 3]` | Эталонная поверхность для оценки |
| `faces` | `[F, 3]`, целые | Треугольники, индексация от нуля |
| `normalization_center` | `[3]` | Центр в исходных координатах |
| `normalization_scale` | scalar, > 0 | Единый масштаб |

Все геометрические массивы и расстояния уже нормализованы:
`x_normalized = (x_world - center) / scale`, `d_normalized = d_world / scale`.
Loader не нормализует их повторно. Для согласованного обучения разных размеров
рекомендуется центр как среднее точек контура и масштаб как максимальное расстояние
точек контура до центра. Инференс NPZ использует сохранённые метаданные; входной
NPY — упорядоченный контур в мировых координатах — нормализуется по этому правилу.

Loader ресемплирует контур равномерно по длине рёбер и выбирает фиксированное число
query-точек. При недостатке точек допускается выборка с повторением. Обучающие
query-точки меняются между эпохами; валидационные фиксированы. Контур не должен
содержать несколько отдельных петель, соединённых искусственными рёбрами.

## Архитектура и функция потерь

PointNet-подобный encoder применяет общий MLP к каждой точке контура,
объединяет max-pooling и mean-pooling и строит латентный вектор. Decoder получает
этот вектор, координаты query и признаки `sin(2^k π x)`, `cos(2^k π x)`.
Выход — одно действительное число. Encoder инвариантен к перестановке уже
ресемплированных точек; нормализация не обеспечивает инвариантность к вращению.

Оптимизируется

\[
L = \lambda_d\operatorname{SmoothL1}(F(q),d(q))
  + \lambda_b\mathbb{E}_{b\in C}F(b)^2
  + \lambda_e\mathbb{E}_{q\in U}(\|\nabla_qF(q)\|_2-1)^2
  + \lambda_m\mathbb{E}_{q\in M}\left[\nabla\cdot
      \frac{\nabla F(q)}{\|\nabla F(q)\|}\right]^2.
\]

`U` — подвыборка query-точек с `|d| < --eikonal-band` (по умолчанию 0.15
в нормализованных единицах). Производные вычисляются autograd; при обучении
строится граф для обратного распространения через eikonal term. Эти веса
настраиваются через `--sdf-weight`, `--boundary-weight`, `--eikonal-weight`.
`M` содержит точки около целевой поверхности. Последний член штрафует среднюю
кривизну её уровней и задаётся параметрами `--minimal-weight`, `--minimal-samples`
и `--minimal-band`. Для минимальной поверхности средняя кривизна равна нулю;
этот физический критерий позволяет донастраивать сеть независимо от точного
совпадения с дискретным ответом учителя. Он использует вторые производные и
заметно увеличивает стоимость шага, поэтому его вес по умолчанию равен `0.001`.
Граничный член мягкий и не обеспечивает точное прохождение нулевого уровня через
контур. Прямого штрафа площади и проверки самопересечений в этой версии нет.

Сохраняются `best.pt` по суммарной validation loss, `last.pt`, параметры запуска,
фактический split и журнал метрик JSONL (loss, SDF regression, boundary, eikonal,
minimality, MAE в нормализованных единицах). Checkpoint содержит параметры архитектуры,
веса и состояние optimizer. CLI пока не поддерживает возобновление обучения;
для нового запуска нужен новый output-каталог. Seed фиксирует выборку и основные
генераторы случайных чисел, но не обещает побитовую одинаковость разных устройств.

## Ограничение открытой поверхности

У открытой плёнки с краем нет глобального понятия «внутри/снаружи». Знак от нормали
ближайшего треугольника — локальная договорённость, которая может разрываться у края
и в областях смены ближайшего листа. Непрерывное скалярное поле с регулярным нулевым
уровнем не представляет свободный край без дополнительных ограничений. Поэтому
Marching Cubes может продолжить поверхность за контур или создать лишние листы.
`--extent` задаёт только вычислительный куб; это не физическое ограничение края.

Ориентация треугольников и знака должна быть согласована во всём датасете.
PointNet по множеству точек не знает направление обхода контура: одинаковый контур
с противоположными знаками target даёт противоречивые примеры. Сам contour также
может допускать несколько стационарных поверхностей; одному детерминированному
выходу нужны согласованный выбор ветви или дополнительные условия.

Экспорт OBJ восстанавливает мировые координаты и создаёт экспериментальный нулевой
уровень поля. Если на решётке нет смены знака, CLI завершится с понятной ошибкой;
при `--field-output` поле всё равно сохранится для диагностики. Это не готовая
сетка с гарантированной границей и не доказанная минимальная поверхность.
Для следующей версии нужно исследовать unsigned distance с извлечением открытой
поверхности либо дополнительное поле, ограничивающее область существования плёнки.

Чтобы оценить пользу нейросети, нужен отдельный тест на сложных контурах: расстояние
до эталона, ошибка границы, площадь, лишние компоненты/листы и время с учётом
извлечения сетки. Одного снижения training loss недостаточно.

Скрипт `scripts/evaluate_prediction.py` сравнивает OBJ с target из NPZ и выдаёт
площади, их отношение, симметричное расстояние «вершина–поверхность» и отклонение
заданного контура от предсказанной сетки в мировых единицах:

```bash
python scripts/evaluate_prediction.py dataset/sample_000000.npz prediction.obj \
  --output evaluation.json
```

Большая площадь или ошибка границы выявляют лишние листы Marching Cubes, даже если
validation SDF loss выглядит приемлемо. Для честного сравнения сложные семейства
контуров следует держать в отдельном test split и не использовать при подборе весов.

## Проверка

```bash
python3 -m pip install pytest
python3 -m pytest tests/test_implicit_nn.py
python3 scripts/train_implicit.py --help
python3 scripts/predict_implicit.py --help
python3 scripts/evaluate_prediction.py --help
```

Тесты проверяют инвариантность encoder, реальные градиенты и обновление весов,
загрузку NPZ, воспроизводимую выборку, разделение групп и исключение test split.
При отсутствии numpy или torch ML-тесты пропускаются.
